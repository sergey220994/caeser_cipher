О проекте

Консольное приложение для шифрования и расшифровки текстовых файлов с ипользованием шифра Цезаря.

Возможности:
-Шифрование текстовых файлов 
-Расшифровка файлов 
-Перебор ключей (BruteForce)


Структура проекта

- MainApp - главное меню и взаимодействие с пользователем 
- Ciper - шифрование и расшифровка текста
- BruteForce - перебор ключей
- FileManager - чтение и запись файлов
- Validator - проверка 
- CiperExeption - класс исключений


Как Запустить 

1. Открыть проект в IDE 
2. Запустить метод main
3. Выбрать нужное действие 


При шифровании и расшифровке необходимо указывать путь к исходному файлу, ключ и путь для сохранения результата

В BruteForce программа самостоятельно перебирает ключи и сохраняет наиболее вероятный вариант расшифровки. 

В шифровании используется циклический сдвиг символов по алфавиту

Результат записывается в новый файл, существующие файлы не перезаписываются.
